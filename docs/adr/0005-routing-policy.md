# ADR-0005：采用国内直连、国外代理

- 状态：已接受
- 日期：2026-09-08

## 背景

MVP 需要一套简单、可解释的基础路由，同时避免国外域名因为使用中国 CDN 地址而误直连。

## 决策

- 私网目标直连。
- 中国域名直连。
- 明确的非中国域名优先代理。
- 对剩余域名进行解析后，中国 IP 直连。
- 其他流量默认代理。
- 使用 SagerNet 的中国域名、非中国域名和中国 IP 二进制 rule-set。
- 详细生成规格以 [RULES.md](../RULES.md) 为准。

## 后果

- 策略顺序明确，可以独立生成和测试。
- 域名规则优先于 IP 规则，减少 CDN 导致的误判。
- 规则集是客户端启动依赖，需要固定版本和显式下载路径。

## 被否决方案

- 仅按 GeoIP 分流：域名经 CDN 时容易误判。
- 中国 IP 规则先于非中国域名：可能让国外域名直连。
- 默认直连：与“国外代理”的项目目标不符。
