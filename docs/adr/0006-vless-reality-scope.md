# ADR-0006：MVP 仅支持 VLESS + REALITY，并忽略单个不兼容节点

- 状态：已接受
- 日期：2026-09-08

## 背景

3x-ui 可输出多种协议和 transport，但不同 Xray 与 sing-box 字段并非总能等价转换。一次支持全部组合会扩大安全和测试风险。用户已指定首期只需要 VLESS + REALITY，并要求忽略单个不兼容节点。

## 决策

- MVP parser 识别 VLESS 分享链接。
- Compatibility Filter 只接受明确启用 REALITY 的节点。
- 首个必须支持并验收的组合为 VLESS + REALITY + TCP，可包含 `xtls-rprx-vision`。
- 其他 transport 只有在输入映射、sing-box 1.14.0 schema 检查和真实连通测试都通过后才加入兼容矩阵。
- 未知协议、不支持 transport、字段缺失或字段非法的单个节点被忽略。
- 至少一个节点有效时继续生成配置；零个有效节点时返回 422。
- 只记录非敏感的忽略原因和数量。

连接必需字段不得使用推测默认值，且绝不自动设置 `tls.insecure: true`。

## 后果

- MVP 范围明确，容易建立高质量 fixture 和连接测试。
- 一个订阅混有其他协议时仍能为兼容节点生成配置。
- 用户可能看不到被忽略节点，因此运维日志和测试环境需提供聚合 warning code，但响应不能泄露敏感详情。
- 新增协议或 transport 需要更新兼容矩阵、测试和文档。

## 被否决方案

- 遇到一个不兼容节点就拒绝整个订阅：可用性较差，不符合用户决定。
- 尽力猜测并转换所有 Xray transport：可能生成看似合法但无法连接的配置。
- 静默接受缺失 REALITY 参数：会产生不安全降级或运行时失败。
